# Glowing Heart & Interactive 3D Galaxy Animation

An interactive web visualizer featuring a glowing particle heart animation and a 3D interactive galaxy particle simulation with customizable modes, controls, audio reactivity, and camera presets.

## ✨ Features

- **Heart Mode (`index.html`)**: Glowing, beating heart particle animation on HTML5 Canvas.
- **Galaxy Mode (`galaxy.html`)**: Interactive 3D galaxy particle simulation with real-time controls (particle count, speed, size, hue, camera presets, bloom/glow effects).
- **Navigation**: Switch between Heart Mode and Galaxy Mode.

## 🚀 Getting Started

Simply open `index.html` or `galaxy.html` in any modern web browser.
